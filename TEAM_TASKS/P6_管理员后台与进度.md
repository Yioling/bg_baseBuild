# 任务卡 · P6 管理员后台 + 课程/计划/进度

## 你的角色
实现公司级管理后台、课程库与师傅定制计划、今日任务检测（AI初评→师傅终评）、当日进度判定、三层进度视图与排名、异常预警、管理员下钻明细。

## 你可写的文件（新建模块，逻辑不要内联进 main.py）
- `backend/courses.py`
- `backend/progress_view.py`
- `backend/quiz.py`
- `backend/admin_back.py`
- 其他你新建的 `backend/*.py`

## 禁止触碰
- `main.py` `db.py` `auth.py` `schemas.py`（路由由 P1 装配，你只写函数）

## 你要做的事（对照 `TEAM_PLAN.md` §5 优先级）
1. **课程库 + 定制计划**：把 `main.py` 中内联的 `/api/admin/courses*` 与 `/api/master/plans*` 逻辑抽到 `courses.py`，导出函数供 P1 装配；支持 `type=检测题库` 与检测题模板引擎（P1）。
2. **今日任务检测（P0 真实 LLM 评分）**：`/api/apprentice/quiz/submit` 当前用答案长度打分——你与 P3 协作：P3 提供 `grade_quiz_answer()`，你在此路由调用它返回真实 AI 初评；师傅终评（`/quizzes/{id}/score`）保留改分。
3. **当日进度判定**：`/api/master/daily-progress` 逻辑抽到 `quiz.py` 或 `admin_back.py`。
4. **三层进度视图**：`/api/progress/company|department|same-master` 抽到 `progress_view.py`；**P1：综合排名算法（完成率×权重+平均分×权重，权重可配置）**。
5. **P0 管理员下钻明细**：新增接口 `GET /api/admin/apprentice/{id}/detail` → 返回该新人培养计划 + 各检测成绩(AI初评/师傅终评) + 每日进度判定；写函数，P1 装配。
6. **P1 异常预警**：识别"长期无进度/多次不通过"的徒弟，提供 `GET /api/admin/anomalies`（数据来自 progress）。
7. **P1 用户筛选**：`/api/admin/users` 支持按 role/status 筛选。
8. **徒弟"已完成"标记自动更新**（P1）。

## 验收标准
- [ ] 课程库 CRUD + 师傅定制计划可用
- [ ] 检测提交走真实 LLM 初评，师傅可终评改分（P0）
- [ ] 三层进度视图 + 权重可配置排名正确
- [ ] 管理员下钻明细可用（P0）
- [ ] 异常预警列表、用户筛选可用
- [ ] 所有函数由 P1 装配，未私自改 main.py
